# Build 47C — Private cloud wallet preparation

This patch does not enable public HTTPS or open a port. The existing operator continues to listen on loopback. Use `LOT_ISSUER_RUNNER="$PWD/runtime/wallet/node_modules/.bin/tsx" bash scripts/lot-browser-operator.sh ACCOUNT` to select the bundled helper's runner. Only explicit manufacturer accounts are permitted; the existing persistent budget still applies. The wallet identity is still pinned to the previously funded dedicated Preprod address. Do not use a mainnet wallet. The bundled runtime is the previously uploaded helper package and lockfile plus the read-only Ledger 9 bootstrap script. The bootstrap does not issue transactions and creates a private local checkpoint after synchronizing. Do not run the same funded wallet simultaneously on two machines. Keep recovery phrase and project token in hidden prompts only. No wallet state is in this patch.

`LOT_PUBLIC_LIVE_RECEIPTS=1` allows the read-only server to resolve a missing key in the static export from the current local journal's public receipt. It reads only the exact public receipt and still verifies ledger state. The gallery is static, new receipts are accessible by their exact link, not automatically listed. Standalone public deployment keeps its existing static-only default.

Targeted source tests passed; a clean runtime install and real cloud wallet sync are not yet verified. Keep service private through SSH until hosted authentication, HTTPS, rate limits, service configuration and independent testing are completed. Do not open ports 4175, 4176, 5173 or 6300 to the public internet.
